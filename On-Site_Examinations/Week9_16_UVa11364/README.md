# UVa 11364 - Optimal Parking

題目連結：[UVa 11364 - Optimal Parking](https://onlinejudge.org/external/113/11364.pdf)

## 題目總結

求停車後拜訪所有商店再回車子的最短路程。

## 關鍵技巧

- 最佳位置在區間內，距離固定為 2*(最大座標-最小座標)。
- 注意 UVa 的輸入通常是多筆測資，輸出格式要完全符合題目要求。

## 解法概念

依題目限制選擇直接模擬、排序、貪心、二分、stack/queue 或 DP。實作時先把資料轉成容易維護的狀態，再依題目規則逐步更新答案。

## 複雜度

- Time: O(n)
- Space: 依資料結構需求，通常為 O(n) 或 O(1)。
