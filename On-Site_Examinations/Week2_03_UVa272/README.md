# UVa 272 - TEX Quotes

題目連結：[UVa 272 - TEX Quotes](https://onlinejudge.org/external/2/272.pdf)

## 題目總結

把文章中的雙引號依序轉成 TeX 的左右引號。

## 關鍵技巧

- 用布林值記錄目前遇到的是開引號或閉引號，其餘字元原樣輸出。
- 注意 UVa 的輸入通常是多筆測資，輸出格式要完全符合題目要求。

## 解法概念

依題目限制選擇直接模擬、排序、貪心、二分、stack/queue 或 DP。實作時先把資料轉成容易維護的狀態，再依題目規則逐步更新答案。

## 複雜度

- Time: O(n)
- Space: 依資料結構需求，通常為 O(n) 或 O(1)。
