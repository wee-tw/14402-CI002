# UVa 12405 - Scarecrow

題目連結：[UVa 12405 - Scarecrow](https://onlinejudge.org/external/124/12405.pdf)

## 題目總結

用最少稻草人覆蓋所有空地。

## 關鍵技巧

- 從左到右貪心，遇到空地就放一個覆蓋目前與後兩格。
- 注意 UVa 的輸入通常是多筆測資，輸出格式要完全符合題目要求。

## 解法概念

依題目限制選擇直接模擬、排序、貪心、二分、stack/queue 或 DP。實作時先把資料轉成容易維護的狀態，再依題目規則逐步更新答案。

## 複雜度

- Time: O(n)
- Space: 依資料結構需求，通常為 O(n) 或 O(1)。
