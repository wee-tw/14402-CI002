# UVa 12149 - Feynman

題目連結：[UVa 12149 - Feynman](https://onlinejudge.org/external/121/12149.pdf)

## 題目總結

計算 n*n 方格中所有正方形數量。

## 關鍵技巧

- 直接使用平方和公式 n(n+1)(2n+1)/6。
- 注意 UVa 的輸入通常是多筆測資，輸出格式要完全符合題目要求。

## 解法概念

依題目限制選擇直接模擬、排序、貪心、二分、stack/queue 或 DP。實作時先把資料轉成容易維護的狀態，再依題目規則逐步更新答案。

## 複雜度

- Time: O(1)
- Space: 依資料結構需求，通常為 O(n) 或 O(1)。
