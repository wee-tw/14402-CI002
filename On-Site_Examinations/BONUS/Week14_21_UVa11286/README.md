# UVa 11286 - Conformity

題目連結：[UVa 11286 - Conformity](https://onlinejudge.org/external/112/11286.pdf)

## 題目總結

統計最熱門的 5 門課組合共有多少學生。

## 關鍵技巧

- 每個學生的課號先排序成標準 key，最後加總最高頻率的所有組合。
- 注意 UVa 的輸入通常是多筆測資，輸出格式要完全符合題目要求。

## 解法概念

依題目限制選擇直接模擬、排序、貪心、二分、stack/queue 或 DP。實作時先把資料轉成容易維護的狀態，再依題目規則逐步更新答案。

## 複雜度

- Time: O(n log n)
- Space: 依資料結構需求，通常為 O(n) 或 O(1)。
