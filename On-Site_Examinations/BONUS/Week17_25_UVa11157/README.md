# UVa 11157 - Dynamic Frog

題目連結：[UVa 11157 - Dynamic Frog](https://onlinejudge.org/external/111/11157.pdf)

## 題目總結

青蛙往返時小石頭只能踩一次，求最小化最大跳距。

## 關鍵技巧

- 把大石頭複製兩次、小石頭一次，最大間隔等於排序後相隔兩格的最大距離。
- 注意 UVa 的輸入通常是多筆測資，輸出格式要完全符合題目要求。

## 解法概念

依題目限制選擇直接模擬、排序、貪心、二分、stack/queue 或 DP。實作時先把資料轉成容易維護的狀態，再依題目規則逐步更新答案。

## 複雜度

- Time: O(n log n)
- Space: 依資料結構需求，通常為 O(n) 或 O(1)。
